How to Add Files:

  1. Upload your file to GitHub:
    • Go to your GitHub repository
    • Create a folder called files (if it doesn't exist)
    • Click "Add file" → "Upload files"
    • Upload your document
  2. Your file URL will be:
    https://YOUR-USERNAME.github.io/YOUR-REPO/files/FILENAME.pdf
  3. Enter the file information below and click "Add File"
